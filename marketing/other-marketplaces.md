# Other places to list

Check each platform's current terms, fees and payout rules before listing; they change. All of them accept an OpenAPI
spec, so the files under `/api/v1/openapi/` work everywhere.

| Platform | What it is | What you'll need |
|---|---|---|
| **RapidAPI** | Largest API marketplace; handles keys, billing, quotas | Provider account, payout details, the 3 listings in `rapidapi-listings.md` |
| **Postman API Network** | Public directory developers browse inside Postman; free to publish | Postman account; import a spec into a public workspace and publish a collection |
| **Zyla API Hub** | API marketplace with built-in billing | Provider application; spec and pricing |
| **APILayer Marketplace** | Curated API marketplace | Provider application; they review submissions |
| **GitHub** | Free discovery: a public SDK/examples repo and README badges | A small examples repo linking to the docs |
| **Product Hunt** | Launch platform for visibility | Maker account; use `launch-posts.md` |
| **XRPL ecosystem** | XRPL developer community, grants and showcases | Use the XRPL post in `launch-posts.md`; consider applying to XRPL grant programs for funding |

Direct sales (no marketplace) already work: customers can buy prepaid credits with XRP, RLUSD or USDC once you give me
your receiving addresses and the database is set up. That keeps 100% of revenue.
