# NoshGuard go-to-market kit

Everything needed to list and promote the APIs. Accounts on marketplaces must be created by you (they need your
identity, payout details and acceptance of their terms); the technical side is ready.

| File | Use |
|---|---|
| `rapidapi-listings.md` | Copy for three RapidAPI listings (name, descriptions, category, tags, plans) and the setup steps |
| `other-marketplaces.md` | Where else to list the same APIs, and what each needs |
| `launch-posts.md` | Ready-to-post launch copy: Product Hunt, Show HN, Reddit, X, LinkedIn, XRPL community |
| `outreach.md` | Who buys this, how to find them, and a short cold email |

Live links (replace the domain if you add a custom one):
- Site: https://noshguard.vercel.app
- Docs and pricing: https://noshguard.vercel.app/api-docs
- OpenAPI specs: `/api/v1/openapi/sanctions.json`, `/api/v1/openapi/xrpl-payments.json`, `/api/v1/openapi/xrpl-tokens.json`, `/api/v1/openapi/all.json`
